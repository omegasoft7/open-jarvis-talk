# Open Jarvis Talk: intro video transcript

The 48-second intro video: [open-jarvis-talk-intro.mp4](open-jarvis-talk-intro.mp4). Captions: [open-jarvis-talk-intro.vtt](open-jarvis-talk-intro.vtt).

## What the video says

Open Jarvis Talk is a plugin for Claude Code. Instead of reading Claude's long replies, you talk to Jarvis, a human-like voice beside your session. Jarvis knows the whole session and can search the web to answer. Your side conversation doesn't go into the session, so it doesn't use up the session's context (its memory of the work). Listening and speaking happen on your Mac; Jarvis thinks with your own Claude plan, so you need no API key. You can tell Jarvis how to answer (for example short and in simple words) and pick its voice. When you ask for a change, Jarvis writes a clear request for Claude, and nothing reaches the session until you approve it.
